# 自然语言理解与需求澄清升级

日期：2026年10月21日。API：0.7.0；Agent：agent_semantic_v2。

## 本轮变化

上一阶段的DeepSeek主要选择搜索、解释、收藏等动作，具体条件仍由有限规则解析。因此“体面点、适合请客和约会”可能被拒绝，页面还直接显示了内部错误码。

现在，启用自然语言理解后，DeepSeek提取结构化动作、条件修改、待澄清问题及已解决问题，并附用户原文。程序检查字段、允许值、来源、数字、否定条件和工具权限，再调用已有推荐系统。模型不能生成候选商户。

实际输入“我想吃一个体面点的饭店，然后适合请客和约会”，已提取为formal/hosting/date三个软偏好，不强制指定菜系，不擅自提高价格。真实Tampa测试返回5家餐厅，页面提示需核对评论。

## 支持范围与澄清

| 表达或条件 | 处理方式 |
| --- | --- |
| 体面、请客、约会、亲子、学习办公、停车、性价比 | 场景软主题，用于查询、排序与相关评论检索；不保证实际满足 |
| 中餐、咖啡、日料等类别及排除条件 | 当前13个类别键；模型映射自由表达，未知菜系需澄清或明确接受关键词检索 |
| 五百米、零点五公里、价格等级二 | 代码核对数值与单位；半径在(0,50]，价格为1–4档 |
| 再便宜一点、近一点、改吃某类 | 结合上下文修改，保留未解决条件 |
| 人均100元 | 说明只有价格等级，询问改用哪档或取消金额限制，不猜人均消费 |
| 必须现在营业、有座位、能预约 | 说明历史数据无法确认；用户可明确改为按历史数据推荐 |
| 过敏、不能放某原料 | 说明无法保证，提示向餐厅核实；需明确取消保证条件才继续普通类别推荐 |
| 同时要求和排除披萨、负距离、过大范围 | 提示冲突或有效范围 |
| 与餐饮无关 | 说明餐厅推荐职责，引导补充餐饮需求 |

这扩展了常见中英文餐饮表达，不能宣称支持所有自然语言、方言或复杂隐含要求。原文校验只能证明提取来源，不能证明理解必然正确。新增场景没有独立人工质量金标，相关词命中也不代表评论正面支持要求。

待澄清条件保留在pending_semantic草稿中，与正式生效条件分开。金额问题后只改菜系不能消除预算问题；“那就价格等级2”可解决预算。接受安静作为软偏好不能取消过敏或实时要求，取消一项保证也不能覆盖另一分句新提出的原料要求。

需要澄清时隐藏旧推荐，并阻止旧列表的解释和收藏。模型不可用或输出非法时回退有限规则，保留尚未解决的事实条件。规则模式允许明确“取消金额限制”“不要求过敏安全保证”“改为历史数据”，并单独验证其余分句，不能借取消夹带未验证要求。

模型不能自行授权收藏，仍需“收藏第二家”等明确指令和有效当前曝光。数值修改必须引用当前轮原文；历史原文仅供恢复待澄清草稿。每轮最多1次模型调用、4个工具步骤、10秒协作式预算；单次模型超时最多6秒。语义提取最多1400输出tokens，受本地更小配置约束。语义调用后解释走本地受控渲染；明确的简单“解释第二家”可把唯一调用留给引用选择。无自动重试。

## 运行

在v2/backend运行：

```powershell
.\.venv\Scripts\python.exe -B -m uvicorn app.main:app --host 127.0.0.1 --port 8100
```

打开并刷新`http://127.0.0.1:8100/agent`。自然语言理解默认勾选，明确标示使用DeepSeek额度；关闭后使用有限规则。API仍需显式`use_model: true`，默认false。密钥继续放在`v2/backend/.env`的`DEEPSEEK_API_KEY`，不填写进网页。`/demo`仍使用原有限查询协议，此次自由表达升级入口是`/agent`。

可依次输入“我想吃一个体面点的饭店，然后适合请客和约会”→“人均100元以内”→“那就价格等级2”→“解释第二家”→“收藏第二家”。前3句依次推荐、澄清金额、保留场景重新推荐。

## 验收与复现

| 检查 | 实际结果与口径 |
| --- | --- |
| 自动化回归 | 297项；较初版新增42项语义/多轮回归 |
| 固定表达集 | 24/24，使用给定的模型输出，只验证应用契约，不是模型理解准确率 |
| 固定多轮场景 | 12场景、37步骤通过，0次模型调用 |
| 真实DeepSeek | 5/5符合预期：截图场景、金额、价格恢复、过敏、无关请求；共4639 tokens |
| 网页 | 恢复真实3轮对话、5张卡片；实时营业要求显示中文澄清并隐藏旧结果 |
| 独立复审 | 检查语义校验、否定与取消、硬条件、模型失败降级和工具权限 |

旧固定多轮recover用例中“现在营业→价格等级2”曾丢失实时营业要求，现必须显式“改为历史数据，价格等级2”再恢复，fixture指纹随之更新。27文档保留历史验收口径。

```powershell
.\.venv\Scripts\python.exe -B -m pytest -q
.\.venv\Scripts\python.exe -B -m app.evaluation.semantic_study
.\.venv\Scripts\python.exe -B -m app.evaluation.agent_study --output-dir data/derived/agent_v1_semantic_regression
```

固定语义产物在data/derived/semantic_v2_acceptance，真实调用本地记录在data/derived/semantic_v2_verification，可提交汇总和代码/fixture SHA256在v2/docs/experiments/semantic_v2。会话标识、凭证、实际评论摘录不随汇总提交。真实调用有非确定性，5条烟测不能估计泛化准确率或证明推荐质量提升，仍需独立人工多轮评测。
