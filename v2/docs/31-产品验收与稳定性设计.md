# 产品验收与稳定性设计

日期：2026 年 10 月 21 日。

本阶段承接产品前后端试运行。目标是让常见的撤销、过期与失败路径可理解、可恢复，并用固定样本记录自然语言和推荐链路的实际表现。沿用 FastAPI、SQLite、原有 Agent 与推荐模型，不改离线训练产物。

## 交互与数据决策

- 收藏页提供取消收藏。撤销记为 `unfavorite` 事件，不借用负反馈 `dislike`；同一账号的重复撤销不重复写事件，后续再次收藏应恢复显示。
- 近期对话仅列出 Agent 存储中仍有效的会话；过期会话的直接访问给出清楚提示和新建入口。会话与账户归属仍由服务器核对。
- 页面补充明确的 401、410、422、429、503 提示；网络结果不确定时沿用现有幂等重试。移动端仍需无横向溢出。

## 验收与运维

- 使用独立于现有语义脚本契约的固定真实表达样本，走产品 API 的注册、对话、推荐路径，记录状态、分类、约束和证据边界。默认 `use_model=false`，不得把规则模式通过率写成 DeepSeek 的理解准确率。
- 本地备份工具对账户、Agent 和反馈三个 SQLite 库在线备份并做完整性检查；处理后的 Yelp 数据和离线模型按已有数据构建流程另行备份。备份含账号与行为数据，只保存在受控目录。
- 单机预览保持仅绑定 `127.0.0.1`；公网入口限流与 HTTPS 由反向代理提供，未配置前不得宣称已公开上线。

完成标准：取消/重新收藏、跨账号隔离、过期会话过滤、错误提示和备份恢复有实测证据；产品质量报告列出样本数、失败项与是否调用模型；全量自动测试通过。
