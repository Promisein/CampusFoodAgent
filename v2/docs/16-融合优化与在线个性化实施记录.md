# 融合优化与在线个性化实施记录

日期：2026年10月20日。本阶段承接14/15文档，完成融合优化、验证集选参和画像在线接入。聚合证据见[17实验报告](17-融合与在线个性化实验报告.md)与[实验目录](experiments/fusion_v1/verification.json)。

## 验收范围

| 工作 | 实现与验收 |
|---|---|
| 固定评估 | 同一完整Tampa交互、原全局时间边界、同目标和固定参考分群；每路最多100、融合最多100 |
| RRF融合 | 去重后计算名次，Σ weight/(k+rank)，确定性同分排序；保留来源、原分和历史种子 |
| validation选参 | 预先声明14种方案；12种RRF配置参与选择，2种旧交替方案作比较；按NDCG@10、Recall@20、Recall@100、名称排序选择 |
| 冻结与test | test前写入selection.json并冻结摘要；test只运行热门、旧双路、所选配置；明确为迭代test |
| 模型导出 | 独立serving_v1全历史快照、120,220个画像、邻居/热门/类别向量、输入/代码指纹及产物校验 |
| 在线推荐 | 可选user_id、请求实际坐标硬过滤、已见排除、三路召回、冻结RRF、来源和种子解释 |
| 故障处理 | 各通道独立禁用；画像/模型不可用规则降级；未知用户地理热门；评论不可用返回空证据与warning；基础商户不可用503 |
| 并发与兼容 | 共享只读模型，每个请求独立缓存；匿名请求保持原规则；经纬度和用户ID校验 |

## 代码位置

- `backend/app/ranking/fusion.py`：融合、预算、去重、白名单。
- `backend/app/evaluation/fusion_study.py`：固定配置研究、验证选择、冻结和报告。
- `backend/app/serving/model.py`：离线导出、校验加载、请求级召回适配。
- `backend/app/personalized.py`：个性化组合、冷启动、降级与响应解释。
- `backend/app/main.py`、`models.py`：API分流及协议扩展。

类别内容复用上一阶段TF-IDF、历史正反馈聚合与价格匹配；ItemCF继续使用正反馈共现、余弦相似度、支持度收缩和Top50邻居。此阶段没有训练新的学习排序模型。

## 复现

在`v2/backend`目录、既有`chedian-eat-agent`环境运行：

```powershell
python -B -m pytest -q
python -B -m app.evaluation.fusion_study
python -B -m app.serving.model
python -B -m uvicorn app.main:app --port 8100
```

输入默认为`data/derived/tampa_full_reviews_v1`；输出分别为`data/derived/fusion_v1`和`data/derived/serving_v1`。需要先按14文档生成完整交互。运行前校验输入manifest，运行后重新核对输入哈希，整目录发布并保留previous备份。原processed和既往实验不被覆盖。

serving构建命令先校验融合实验manifest、selection摘要及输入哈希。加载时校验冻结选择摘要及模型文件哈希，拒绝不一致版本。模型进程内缓存，更新文件后重启服务加载；不支持运行中热切换。

请求示例（将user_id替换为本地画像中的Yelp用户ID；未知ID触发冷启动）：

```json
{
  "query": "coffee",
  "user_id": "a-local-yelp-user-id",
  "latitude": 27.9506,
  "longitude": -82.4572,
  "radius_km": 10,
  "max_price_level": 2,
  "top_k": 5
}
```

POST `/api/v2/recommend`。不传user_id沿用原规则。响应增加`metadata`、`channel_scores`与`reason_business_ids`，说明画像命中、快照版本、来源名次/原分、历史种子和降级原因。

## 边界

离线回放依旧使用2017/2019截止点；在线演示单独使用全部现有历史，快照截止`2022-01-20 00:00:00`，不能拿在线快照评估2019测试目标。它是公开数据的历史偏好演示，不是实时画像、真实账户认证或生产用户服务。

线上使用实际请求位置，离线simulated_geo使用历史坐标均值代理，两者有差异。个性化路径当前不使用query文本排序，响应明确`query_used_for_ranking=false`；不要把类别TF-IDF当成查询语义向量模型。冷用户有请求位置时可以返回地理热门，离线无历史且无代理位置时仍为空。

硬过滤包括城市、数据集is_open标记、已知价格上限、半径和已见排除。is_open不表示现实此刻营业，尚未按时区/营业时段做判断。缺少合法候选时返回空列表。模型画像整体不可用时无法知道seen，规则降级不保证排除历史已见，响应有model_unavailable；单通道故障保留健康画像与seen过滤。

代表评论沿用processed展示证据，不参与历史回放模型训练，不声称是对应历史截止点的RAG证据。学习排序、查询语义、混合检索、受控Agent、真实曝光反馈留待后续阶段。
