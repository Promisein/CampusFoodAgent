# 产品质量验收与部署准备

日期：2026 年 10 月 21 日，API 版本 0.8.1。本阶段完成收藏撤销、过期会话过滤、页面错误提示、固定真实表达验收、SQLite 在线备份与反向代理模板。

## 验收口径

运行：

```powershell
cd v2/backend
.\.venv\Scripts\python.exe -B -m app.evaluation.product_quality
```

样本为 `data/fixtures/product_quality_cases_v1.json` 中的 30 条人工编写中文用餐表达，包含类别、距离、价格、场景偏好、不合理要求、实时信息和越界请求。脚本通过独立临时账户与 SQLite 库调用 `/api/v2/product/*`，使用本机已处理的 Tampa Yelp 数据，固定 `use_model=false`。检查状态、类别和条件解析以及返回餐厅的距离/价格硬约束，不调用 DeepSeek。结果保存在忽略 Git 的 `data/derived/product_quality_v1_acceptance`。本轮 30/30 条通过、模型调用 0 次；这只是固定样本的规则模式合同验收，不能解释为开放式自然语言准确率、真实用户满意度或餐厅主观相关性。此前 `semantic_v2` 的 24 条脚本模型计划合同也不是独立真实模型盲测。

首轮未通过的是“带孩子吃饭”和“三公里内的披萨店”；补充“带孩子/带小孩”场景别名及 1–50 公里常见中文数词后，同批样本全部通过。超过 50 公里或无法解析的中文数词仍提示澄清。新增规则不意味着任意中文表达都可被规则模式理解；模型模式需另行人工评测。

## 收藏与会话

取消收藏写入 `unfavorite`，不会计作“不喜欢”。重复取消只返回 `removed=false`，再次收藏可恢复；页面显示已收藏状态。近期对话会核对 Agent 会话是否还有效，过期的不会继续显示；直接打开过期会话会提示新建。Agent 会话仍为 24 小时有效，账户登录会话为 7 天，两者期限不同。

## 在线备份与恢复

在 `v2/backend` 执行，输出目录必须尚不存在：

```powershell
.\.venv\Scripts\python.exe -B -m app.product.backup --output-dir D:\secure-backups\campusfood-20261021
```

工具使用 SQLite 在线备份接口分别备份 `accounts.sqlite3`、`sessions.sqlite3`、`events.sqlite3`，对备份执行 `PRAGMA integrity_check`，写入文件散列与清单。三个数据库各自一致，但**不是跨数据库同一时刻的原子快照**。恢复时先停服务，在保留原件的前提下把三个文件按清单放回 `data/derived/product_v1/`、`agent_v1/`、`demo_events/` 对应位置，再启动并测试登录、对话和收藏。备份包含账号与行为信息，只应放在受控目录；Yelp `data/processed` 和离线模型另行保存或重建。此次在本机运行了一次真实数据备份，目录位于 `data/derived/product_backups/`，不提交 Git。

## HTTPS 与入口限流

`v2/backend/deploy/nginx.product.example.conf` 是待替换域名和证书路径的 Nginx 模板：仅转发 `/app` 与产品 API，设置登录/注册和一般 API 的按 IP 速率限制，并通过 HTTPS 提供服务。模板依据 Nginx 官方[限流模块](https://nginx.org/en/docs/http/ngx_http_limit_req_module.html)、[代理模块](https://nginx.org/en/docs/http/ngx_http_proxy_module.html)和[HTTPS 配置](https://nginx.org/en/docs/http/configuring_https_servers.html)编写。该模板尚未在目标服务器上执行 `nginx -t` 或 TLS 验收，不能据此宣称公网可用。正式部署需将 `CAMPUSFOOD_COOKIE_SECURE=true`、Uvicorn 绑定内网/本机、证书和域名换成真实值，完成备份恢复演练、日志监控、真实模型对话人工评测与数据使用许可检查。
