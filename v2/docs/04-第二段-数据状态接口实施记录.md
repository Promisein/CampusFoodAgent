## 5. 错误处理

如果 manifest 出现以下问题，状态接口返回 HTTP 503：

- `data_manifest.json` 不存在；
- manifest schema 不合法；
- 路由需要的关键键缺失。

错误响应格式：

```json
{
  "detail": "Processed dataset unavailable: <具体原因>"
}
```

这样可以区分“服务正常但数据为空”和“processed 数据不可用”。
