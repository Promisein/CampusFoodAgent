## 3. 新增集成验收

### 3.1 processed 全链路可追溯性

集成测试直接读取实际 processed 数据，并验证：

1. 状态接口的商家数、交互数和代表评论数与 manifest 一致；
2. 实际加载的 Business 数量为 3,805；
3. 实际加载的代表评论总数为 29,092；
4. 推荐结果中的每个 `business_id` 都存在于 `businesses.jsonl`；
5. 每个 `document_id` 都属于当前推荐商家的代表评论；
6. 推荐结果全部来自 Tampa、处于营业状态、价格存在且符合上限；
7. 返回距离不超过请求半径；
8. 默认 API 不返回 `v2_yelp_biz_*` fixture ID。

### 3.2 fixture 降级为测试数据

测试先确认 fixture 文件仍然存在，再把 fixture 加载函数替换为主动报错函数。默认推荐 API 仍能正常返回 processed 结果，证明 fixture 不参与默认在线请求。

### 3.3 空结果与稳定性

- 对 Tampa 发起不可能命中的位置请求，接口返回 HTTP 200 和合法空列表；
- 对分数、距离完全相同的 processed 商家，结果按 `business_id` 稳定排序；
- 每个商家的证据保持与自身 `business_id` 一致，不发生跨商家串联。
