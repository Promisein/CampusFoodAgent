# 画像感知基线召回与离线评估实施记录

日期：2026年10月20日。阶段：离线基线召回与评估，未接入在线API。

## 阶段目标与交付

在现有processed、时间切分和画像基础上，固定评测协议，实现热门、ItemCF与候选合并；跑真实10万交互并保留失败结果。训练与回放使用CPU和Python标准库，无新增依赖。

新增代码：

- `backend/app/retrieval/baselines.py`：输入校验、全局截止点画像、历史热门统计、ItemCF邻居、模拟地理过滤、交替合并。
- `backend/app/evaluation/baseline_replay.py`：窗口与目标选择、指标、分群、资格覆盖、互补性、匿名失败案例、源文件与代码SHA256、CLI及确定性输出。
- `backend/tests/test_recall_baselines.py`、`test_baseline_evaluation.py`：20项新增测试。

旧processed、旧time_split_v1、旧profile_v1与在线规则引擎保持原样。新画像单独写在实验目录中，不覆盖已有6,046份快照。

## 时间与标签协议

旧leave-two-out保证用户自身历史顺序，但不能直接保证所有用户的协同统计早于目标。本阶段使用全局冻结窗口：

| 阶段 | 截止点 | 历史交互数 | 未来评测窗口 |
|---|---|---:|---|
| validation | 2017-11-08 20:34:02 | 60,000 | 截止点至test截止点，右开 |
| test | 2019-05-30 23:02:52 | 80,000 | 截止点至数据末尾 |

截止点按排序交互的60%/80%位置取值，实际分段以时间比较为准，同时间戳整体不进入历史。画像、共现、热度、历史平均分冻结于截止点。测试时可以使用已经发生的验证窗口交互；不在测试窗口内增量更新，不根据测试结果调参。

每窗口每用户选择第一条4—5星且在截止点未访问过的商户评论为正目标。这是“固定窗口内下一个新商户高分目标”任务，不是点击预测。低星、重复访问、无新高分目标用户数量单独报告。目标不在合法候选库时仍记总体未命中，不强插正样本。

Cold/Light/Warm按当前截止点历史交互数0/1—4/至少5定义，和旧画像阶段按完整子集1/2—4/至少5分组不同，不混用分母。

## 模型规则

热门分：`log(1+历史正向用户数) × 贝叶斯历史平均评分/5`；均分先验为全局历史均分，先验权重5。

ItemCF：同一用户—商户以最后一次历史评分决定是否喜欢，4星权重1、5星权重2；商户余弦相似度乘以`共现数/(共现数+5)`做收缩，每商户保存Top50邻居。推理从正向种子扩散，排除已交互商户，返回种子商户ID作解释。

合并：两路候选按ItemCF、热门交替取，去重后截到100。它不是RRF或学习排序。两路各Top100并集最多200，合并预算100可能丢掉部分命中，所以同时报告独占命中和合并结果。

## 两类实验与候选资格

1. city_preference：全城历史可见商户，排除已访问商户。不使用伪造查询、请求位置、预算或当前开业标记。
2. simulated_geo：历史商户坐标均值作为位置代理，半径10km、价格等级不超过4，价格或坐标未知排除。无历史用户没有位置，保持空候选并报告。热门分再除以`1+距离km`。

历史可见性由截止点前至少一条评论定义，是代理而非真实开业日期。Business的stars/review_count/is_open不进入历史统计；价格、类别与坐标仍是静态快照代理，不声称完全恢复历史状态。类别和价格偏好字段已输出，本阶段协同分只使用正向种子和评分权重。

## 复现与产物

在`v2/backend`目录运行：

```powershell
$env:PYTHONNOUSERSITE = '1'
$env:PYTHONDONTWRITEBYTECODE = '1'
$foodPython = 'D:\anaconda3\envs\chedian-eat-agent\python.exe'
& $foodPython -B -m pytest tests/ -q -o addopts= -p no:cacheprovider
& $foodPython -B -m pip check
& $foodPython -B -m app.evaluation.baseline_replay --data-dir data/processed --output-dir data/derived/baseline_recall_v1
```

| 文件 | 用途 |
|---|---|
| experiment_manifest.json | 输入SHA256、代码SHA256、配置和环境 |
| metrics.json | 总体/分群、资格覆盖、互补性、失败案例 |
| report.md | 自动生成的完整报告 |
| profiles.jsonl | 两个全局截止点画像；包含目标冷用户空画像 |
| neighbors.jsonl | 邻居表、相似度、共现支持数 |
| request_trace.jsonl | 三路候选、目标排名和前五条候选召回原因 |

输出目录必须与输入目录及其祖先/子目录分离；已有无本实验manifest的非空目录拒绝覆盖。完整产物只在被git忽略的derived保存。聚合结果见`docs/experiments/baseline_recall_v1`，不复制原评论、用户画像或逐请求候选到公开文档。

## 验证和完成边界

原有41项测试通过后开发；新增测试先观察缺失功能失败，再实现通过。覆盖手算余弦/收缩、差评更新、严格同时间戳边界、输入异常、未来隔离、地理过滤、不可见正目标、冷用户、指标分母、去重、失败案例、CLI及确定性重跑。最终测试数与执行结果见下方收尾记录。

真实实验生成81,904条画像、5,876条邻居行、37,642条场景请求trace；源文件SHA256未改变。画像行数包含两个截止点历史用户与目标冷用户，不等于旧Warm画像数量。

完成的是离线热门/协同基线与实验链路，语义/内容、RRF、LightGBM、在线个性化、混合RAG和Agent仍未实现。具体效果和下一步见[实验报告](13-基线召回实验报告.md)。
